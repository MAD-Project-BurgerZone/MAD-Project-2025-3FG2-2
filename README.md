# 📱 Mobile App Development Project

## 📌 Project Title
Burger Zone

## 🎓 Course Information
- Course: Mobile App Development
---

## 📖 Project Overview

This mobile application was developed as a requirement for the Mobile App Development course. The goal of this project is to design and implement a functional, user-friendly, and responsive mobile application for Demo purposes.

The application demonstrates core mobile development concepts including UI design, navigation, state management, and data handling.

---

## 🎯 Objectives

- Develop a functional mobile application.
- Apply mobile UI/UX design principles.
- Implement CRUD operations (Create, Read, Update, Delete).
- Use Intents and useExtra's for mock database

---

- Programming Language: Java
- Framework: Android Studio
- IDE: Android Studio
